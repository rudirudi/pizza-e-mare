# Pizza & Mare

Sito statico della pizzeria d'asporto Pizza & Mare.

- `public/index.html`: pagina unica (menù, offerte, carrello dimostrativo)
- `public/assets/`: immagini
- `vercel.json`: configurazione Vercel (nessuna build, cartella `public`)

Note: offerte e dati "Chi siamo" sono di esempio; l'invio ordini e il pagamento Stripe non sono ancora collegati. L'intestazione `X-Robots-Tag: noindex` va rimossa al passaggio sul dominio definitivo.
